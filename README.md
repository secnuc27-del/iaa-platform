# meu-siteIAA

Site criado do zero

# Interligação Alto Acre (IAA) - versão unificada

Conforme solicitado, todo o front-end foi **unificado em um único arquivo**:

- `index.html` (contém HTML + CSS + JavaScript no mesmo arquivo)

## Como executar

Abra `index.html` no navegador.

## O que existe na versão unificada

- Capa pública
- Login e cadastro
- Escolha de perfil e completar perfil
- Boas-vindas
- Painel interno
- Áreas: serviços, empresas, vagas, classificados, vídeos, fotos, perfil, publicações, desempenho, configurações, ajuda, sobre, contato e admin

## Observação

- A autenticação continua simulada com `localStorage` (protótipo front-end).
